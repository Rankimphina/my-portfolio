# Rankim's Portfolio

This is my personal portfolio website. It shows a list of projects I have built.
You can search for a project by name and it will show you the full details like
the description, technologies used and a link to the GitHub repo.

## Features
- View a list of all my projects on the home page
- Search for a project by name to see its full details
- Each project shows a description, technologies used and a link to the GitHub repo
- Download my resume directly from the website
- Contact me through email, LinkedIn or GitHub
- Works on both mobile and desktop screens
